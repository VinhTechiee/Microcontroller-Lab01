# Microcontroller-Lab01

## Course
Microprocessors-Microcontrollers (CO3009)

## Lab 01: LED Animations

## Description
This repository contains STM32F103C6 projects developed using STM32CubeIDE and simulated with Proteus.

## Exercises

- Exercise 1: Two LEDs
- Exercise 2: Traffic Light
- Exercise 3: Four-Way Traffic Light
- Exercise 4: Seven-Segment Display
- Exercise 5: Traffic Light Countdown
- Exercise 6: LED Clock
- Exercise 7: clearAllClock
- Exercise 8: setNumberOnClock
- Exercise 9: clearNumberOnClock
- Exercise 10: Analog Clock

## Tools

- STM32CubeIDE
- Proteus
- STM32F103C6
